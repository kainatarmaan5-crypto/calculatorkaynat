# Simple Calculator

This project contains two implementations of a simple calculator:

1. **Web-based GUI Calculator** ([index.html](file:///C:/Users/Student/calculator/index.html))
   - Modern, responsive dark-mode UI
   - Full mouse click and keyboard input support (number keys, `+`, `-`, `*`, `/`, `Enter`/`=`, `Backspace`, `Escape`)
   - Handles decimal calculations, percentage, and division-by-zero protection
   - **How to run:** Double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox).

2. **Python CLI Calculator** ([calculator.py](file:///C:/Users/Student/calculator/calculator.py))
   - Terminal-based interactive calculator
   - Supports addition, subtraction, multiplication, division, power (`^`), and modulo (`%`)
   - Input validation and division-by-zero error handling
   - **How to run:**
     ```bash
     python calculator.py
     ```
